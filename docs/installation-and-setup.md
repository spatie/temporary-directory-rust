---
title: Installation
weight: 3
---

You can install the package via Cargo. Add the crate to your application's `Cargo.toml`:

```toml
[dependencies]
spatie-temporary-directory = "1"
```

Requires Rust 1.89 or newer. You can install Rust with [rustup](https://rustup.rs/). No PHP runtime or external programs are required.
